# Clear Earth Safety Consultancy LLC (شركة استشارات السلامة ذ.م.م)
## Official UAE Corporate Website

A modern, high-performance, responsive corporate website built for **Clear Earth Safety Consultancy LLC**, a premier safety engineering, third-party inspection, equipment certification, technical workforce training, and industrial instrumentation firm based in **Al Satwa, Dubai, United Arab Emirates**.

---

4. **Interactive Lead Generation**:

## 🚀 Getting Started

### Development Server
```bash
npm install
npm run dev
```

### Production Build & Preview
```bash
npm run build
npm run preview -- --port 4173
```

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS with custom brand theme tokens
- **Icons**: Lucide React
- **Typography**: Inter (Latin) & Cairo (Arabic)
